# Quick Sort Ödevi

Bu proje, Quick Sort algoritmasının Haskell, C++ ve Python dillerindeki uygulamalarını karşılaştırır.

## Proje yapısı

```text
quick_sort_odev/
├── quick_sort_odev.ipynb
├── README.md
└── src/
    ├── QuickSort.hs
    ├── quicksort.cpp
    └── quicksort.py
```

## Çalıştırma

`quick_sort_odev.ipynb` dosyasını proje ana klasöründen Jupyter Notebook veya JupyterLab ile açın. Notebook, dil uygulamalarını `src` klasöründen okur.

Haskell testi için GHC, C++ testi için `g++` veya `clang++` gereklidir. Python uygulaması için Python yeterlidir. Bellek ölçümü için isteğe bağlı olarak `psutil` kurulabilir:

```bash
pip install psutil pandas matplotlib
```
